# Glossário em linguagem simples

Use estas explicações na primeira vez que a palavra aparecer no material.

## Termos
| Palavra | Explicação simples |
|---|---|
| Conta salário | Conta aberta pela empresa só para receber o salário. Não tem tarifa de manutenção e permite levar o dinheiro para outro banco. |
| Conta corrente | A conta do dia a dia: Pix, cartão, pagamentos e investimentos. É uma escolha da pessoa. |
| Portabilidade de salário | Pedir para o salário ir automaticamente para outro banco, sem custo. |
| Pacote de serviços | Um conjunto de serviços da conta corrente (transferências, saques, extratos) por uma tarifa mensal. |
| Isenção de tarifa | Período em que a tarifa não é cobrada, sob uma condição. |
| Anuidade | A tarifa anual do cartão de crédito, cobrada em parcelas na fatura. |
| Cashback | Parte do valor das compras que volta para você, como crédito na fatura ou na conta. |
| Programa de pontos | Programa em que as compras e o uso dos produtos viram pontos, trocados por produtos, descontos ou milhas. |
| Crédito consignado | Empréstimo com as parcelas descontadas direto do salário. Costuma ter taxa menor. |
| Antecipação do 13º | Receber antes uma parte do 13º salário, pagando juros; a dívida é quitada quando o 13º cai. |
| Cheque especial | Limite de crédito da conta corrente usado quando o saldo acaba. Tem juros altos: é para emergências. |
| CET (Custo Efetivo Total) | O custo total de um empréstimo, com juros, impostos e tarifas. É o número para comparar créditos. |
| IOF | Imposto cobrado em empréstimos e algumas operações financeiras. |
| CDB | Aplicação de renda fixa: você empresta dinheiro ao banco e recebe juros. |
| Liquidez diária | Poder resgatar o dinheiro aplicado em qualquer dia útil. |
| Previdência privada | Uma reserva de longo prazo para a aposentadoria, além do INSS. |
| Análise de crédito | A avaliação que o banco faz antes de liberar crédito. Pode aprovar, reduzir ou negar. |
| Correntista | Quem tem conta corrente no banco. |
