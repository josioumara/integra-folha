# Roteiros de clique (ponta a ponta)

Os testes do `pytest` conferem os serviços e as rotas. Estes roteiros conferem a **tela**: abrem o Chrome, entram
com um usuário de teste, clicam e conferem o que aparece, como uma pessoa faria.

## Como rodar

Na pasta `integra-folha`, com o `.venv`:

```powershell
python -m pip install -r tests/e2e/requirements.txt    # uma vez (Playwright 1.63.0)
python tests/e2e/rodar.py                                # todos os roteiros
python tests/e2e/rodar.py cnpj_do_grupo parametros       # só os escolhidos
```

Precisa do **Google Chrome** instalado (o Playwright usa o Chrome do computador). **Não gasta nada:** tudo roda em
modo MOCK, sem chave de API.

## O que cada execução faz

1. cria uma pasta temporária com um banco SQLite novo (o banco local e o PostgreSQL não são tocados);
2. prepara os dados do roteiro num processo separado (usuários de teste, um envio parado em pendências...);
3. sobe o servidor numa porta livre;
4. percorre as telas e mostra `OK` ou `FALHOU` em cada passo, mais os erros de JavaScript da página;
5. desliga o servidor e apaga a pasta.

O resultado final é "tudo certo" (código de saída 0) ou "ALGO FALHOU" (código 1). Um erro de JavaScript na página
também reprova o roteiro.

## Como escrever um roteiro novo

Um arquivo em `tests/e2e/roteiros/`, com:

- `DESCRICAO`: uma frase;
- `preparar() -> dict`: roda **num processo separado**, já apontado para o banco temporário; cria os dados e
  devolve o que o roteiro precisa saber (ex.: o CNPJ usado). Os imports da aplicação ficam **dentro** da função;
- `percorrer(navegador, endereco, dados, conferir, erros_da_pagina)`: os cliques. Use `apoio.entrar(...)` para
  entrar e `conferir("descrição", condição)` para cada passo.
- Em `wait_for_function` e `evaluate`, escreva sempre uma **função** (`"() => document.querySelector(...)"`), nunca
  uma expressão solta (`"document.querySelector(...)"`): a expressão solta o Playwright roda com `eval`, que a
  política de conteúdo do site bloqueia (ADR-110); a função ele roda sem `eval`.

O nome do arquivo não começa com `test_`: o `pytest` não o recolhe (cada roteiro leva dezenas de segundos).
